# TaskMind 🤖

A premium, AI-driven Project Management Dashboard built with Next.js.

## Features
- **Intelligent Dashboard**: Real-time project tracking and AI-driven insights.
- **Premium UI**: Modern dark mode aesthetic with glassmorphism and smooth animations.
- **AI Command Center**: Integrated bot status and efficiency metrics.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS with Design Tokens
- **Identity**: Configured for Mayank09811 (mmkk46122@gmail.com)

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Open the application**:
   Navigate to [http://localhost:3000](http://localhost:3000)

## GitHub Integration

To push this project to your public GitHub repository:

1. **Create a new public repository** on GitHub named `TaskMind`.
2. **Link the local repository**:
   ```bash
   git remote add origin https://github.com/Mayank09811/TaskMind.git
   ```
3. **Push your code**:
   ```bash
   git branch -M main
   git push -u origin main
   ```
